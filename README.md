# 마리봇 체험 플랫폼

디스코드 서버에 초대하지 않아도 브라우저에서 바로 마리봇을 체험해볼 수 있는 데모 웹 플랫폼입니다.
디스코드 UI(서버 목록, 채널, 채팅창)를 재현한 화면에서 마리봇과 대화할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

`http://localhost:3000` 접속.

## 실시간 AI 응답 모드

기본 상태(API 키 없음)에서는 `!도움말`, `!운세`, `!칭찬` 같은 미리 정해진 명령어와
간단한 규칙 기반 응답으로만 동작하는 **데모 모드**입니다.

실제 AI가 생성하는 응답을 받고 싶다면 `.env` 파일을 만들고 Anthropic API 키를 넣어주세요.

```bash
cp .env.example .env
# .env 파일을 열어 ANTHROPIC_API_KEY=sk-... 입력
```

키가 설정되면 서버가 자동으로 `live` 모드로 전환되어 `bot/marie.js`의
페르소나 프롬프트를 기반으로 실제 응답을 생성합니다.

## 구조

- `server.js` — Express 서버, `/api/chat`, `/api/status` 라우트
- `bot/marie.js` — 마리봇 페르소나 정의 + 데모 응답 / 실시간 응답 로직
- `public/` — 디스코드 스타일 데모 UI (정적 HTML/CSS/JS)

## 참고

이 프로젝트는 실제 디스코드 서버/봇 토큰과는 무관한 **웹 데모**입니다.
실제 디스코드 봇으로 배포하려면 `discord.js` 등을 이용해 `bot/marie.js`의
페르소나 로직을 디스코드 이벤트 핸들러에 연결하면 됩니다.
