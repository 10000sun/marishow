# marishow — 마리봇 체험 웹 데모

디스코드 서버에 초대하지 않아도 브라우저에서 **마리봇**을 체험해볼 수 있는 디스코드 스타일 웹 데모입니다.
서버 목록·채널·채팅창을 흉내 낸 화면에서 슬래시(`/`) 명령어를 입력해 보거나 마리와 잡담할 수 있습니다.

## 원본 마리봇과의 관계

- 실제 마리봇은 별도의 **비공개 디스코드 봇 프로젝트**입니다. 이 저장소에는 그 봇의 코드·토큰·서버 데이터가 **들어 있지 않습니다**.
- 이 저장소는 마리봇의 명령어 체계와 캐릭터(페르소나)를 보여주기 위한 **데모 전용 재구현**입니다. 디스코드 API(`discord.js` 등)는 사용하지 않습니다.
- 지갑·주식·상점·복권 등의 경제 기능은 브라우저 메모리에 있는 **가짜(mock) 데이터**로 동작하며, 실제 봇의 정확한 규칙(개장 시간, 세율 등)을 그대로 계산하지는 않습니다.

## 기능

- **채널별 명령어 체험** (`public/js/commands.js`): `마리-대화`, `지갑-경제`, `주식`, `상점`, `복권`, `미니게임`, `프로필-위키`, `아이디등록`, `홍보-스누즈`, `기타` 채널과 도움말·관리자 전용 채널이 있고, 채널마다 쓸 수 있는 `/` 명령어가 다릅니다. 입력창에 `/`를 치면 자동완성 힌트가 뜹니다.
- **관리자 모드 토글**: 우측 상단 스위치를 켜면 관리자 전용 채널과 관리자 명령어(`/지급`, `/주식 변동` 등)를 시연할 수 있습니다.
- **가짜 경제 상태** (`public/js/state.js`): 주식 시세가 4초마다 무작위로 움직이고, 목(mock) 유저 3명(유저1~3)이 있어 여러 명이 있는 서버처럼 보이게 합니다. 상태는 새로고침하면 초기화됩니다.
- **AI 잡담** (`마리-대화` 채널): 서버가 `/api/chat`으로 요청을 받아 마리 페르소나로 답합니다.
  - `ANTHROPIC_API_KEY`가 **없으면** `demo` 모드: 몇 가지 키워드(안녕, 고마워 등)에 대한 정해진 답변만 합니다.
  - `ANTHROPIC_API_KEY`가 **있으면** `live` 모드: Anthropic API로 실제 답변을 생성합니다(최근 대화 10개를 함께 전송, 응답 최대 300 토큰).

## 기술 스택

- Node.js + Express 4, dotenv
- `@anthropic-ai/sdk` (live 모드에서만 동적 로드)
- 프론트엔드: 빌드 과정 없는 정적 HTML/CSS/바닐라 JS (`public/`)
- 배포: Render 블루프린트(`render.yaml`)

## 실행 방법

```bash
npm install
npm start          # http://localhost:3000
# npm run dev      # 파일 변경 시 자동 재시작 (node --watch)
```

API 키 없이도 바로 실행되며 `demo` 모드로 동작합니다. 실제 AI 응답을 쓰려면:

```bash
cp .env.example .env
# .env 파일을 열어 ANTHROPIC_API_KEY 값을 채우세요
```

`.env`는 `.gitignore`에 포함되어 있어 커밋되지 않습니다. 키를 코드나 저장소에 직접 적지 마세요.

## 환경변수

| 이름 | 필수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `ANTHROPIC_API_KEY` | 아니오 | (없음) | 설정하면 `live` 모드, 비우면 `demo` 모드 |
| `PORT` | 아니오 | `3000` | 서버 포트 |

현재 모드는 `GET /api/status`(`{"mode":"live"|"demo"}`)로 확인할 수 있습니다.

## Render 배포

`render.yaml`에 무료 플랜 웹 서비스가 정의되어 있습니다(`npm install` → `npm start`).
Render 대시보드에서 `ANTHROPIC_API_KEY`를 직접 입력해야 하며(`sync: false`라서 파일에는 값이 없습니다), 입력하지 않으면 `demo` 모드로 배포됩니다.

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| `GET` | `/api/status` | 현재 모드 반환 |
| `POST` | `/api/chat` | `{ message, history? }` → `{ reply, mode }`. `message`는 비어 있지 않아야 하고 1000자 이하 |

## 프로젝트 구조

```
server.js            Express 서버, /api/status, /api/chat
bot/marie.js         마리 페르소나(시스템 프롬프트), 데모 응답 / 실시간 응답 로직
public/index.html    페이지 (디스코드 스타일 셸)
public/js/state.js   가짜 경제 상태(지갑·주식·상점·복권 등)
public/js/commands.js 채널 정의와 / 명령어 구현
public/js/app.js     채널 전환, 메시지 렌더링, 입력 처리, /api/chat 호출
public/css/style.css 스타일
render.yaml          Render 배포 설정
```

## 상태와 한계

- 체험용 데모입니다. 경제 데이터는 브라우저 메모리에만 있고 저장되지 않습니다.
- `/api/chat`에는 요청 횟수 제한(rate limit)이 없습니다. `live` 모드로 공개 배포하면 누구나 API 비용을 쓸 수 있으니, 공개 URL에 키를 연결할 때는 제한을 추가하거나 비용 한도를 설정하세요.
- live 모드의 모델 이름은 `bot/marie.js`에 하드코딩되어 있습니다(`claude-sonnet-5`). 바꾸려면 해당 파일을 수정하세요.
- 테스트 코드는 없습니다.
